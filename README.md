# 📝 Smart MemoPad (수식 계산 메모장)

**Smart MemoPad**는 일반 메모장의 편리함과 공학용 수식 계산기의 강력함을 결합한 **PySide6 기반 경량 데스크톱 유틸리티**입니다.
개발자, 엔지니어, 연구자가 코딩이나 문서 작업 중 상단 입력창 또는 **메모장 본문 안에서 즉시 수식을 계산**하고 10진수와 16진수 결과를 직관적으로 확인할 수 있습니다.

---

## 🌟 주요 특징 및 기능

### 1. 🧮 16진수, 2진수 및 정밀 수식 계산 지원 (No eval)
* 파이썬의 보안 취약점인 `eval()`을 일체 사용하지 않고, **안전한 자체 재귀 하강 파서(Recursive Descent Parser)**를 탑재했습니다.
* **16진수 & 2진수 연산 완벽 지원**:
  * 16진수: `0xFF + 1`, `0x1000 - 0x10`
  * 2진수: `0b1010 + 2`, `0b1111 * 2`
* **지능형 결과 표기**:
  * 정수 결과: `수식 = 10진수 ( 0x16진수 )` 형태로 16진수 동시 표기
  * 실수 결과: `1 / 2 = 0.5` 형태로 순수 10진수만 깔끔하게 표시 (불필요한 `0x0` 제거)
* **임의 정밀도 무한 정수 연산**: 64비트 및 128비트 이상의 초거대 정수도 오차 없이 정확하게 계산 (`0xFFFFFFFFFFFFFFFF = 18446744073709551615`)
* **연산자 우선순위 지원**:
  * `^` (거듭제곱, 우결합: `2^3^2 = 2^9 = 512`)
  * `+ -` (단항 부호)
  * `* / %` (곱셈, 나눗셈, 나머지)
  * `+ -` (덧셈, 뺄셈)
  * `( )` (괄호 우선순위)

### 2. ⚡ 메모장 내 인라인 수식 계산 (`Ctrl + Enter` / `F5`)
* 상단 입력창으로 이동하지 않고도 **메모 본문에서 작성 중인 수식을 바로 계산**할 수 있습니다:
  * 마우스로 수식을 드래그 선택 후 `Ctrl + Enter` → 그 자리에 `= 결과` 추가
  * 커서가 있는 줄에서 `Ctrl + Enter` 또는 `F5` → 해당 줄 수식 자동 분석 후 결과 삽입
  * `점심값: 7000 + 1500` → `점심값: 7000 + 1500 = 8500 ( 0x2134 )`
  * 이미 계산된 수식을 수정 후 다시 누르면 최신 결과로 자동 갱신

### 3. 🖥️ 편리한 작업 환경 & UX
* **수식 입력 히스토리 (`↑` / `↓`)**: 상단 입력창에서 방향키로 이전에 계산했던 수식들을 손쉽게 다시 불러오기
* **테마 전환 (`F6`)**: 눈의 피로를 덜어주는 **다크 모드**와 깔끔한 **라이트 모드** 원클릭 토글 (설정 보존)
* **글꼴 크기 실시간 조절 (`Ctrl + ↑ / ↓`)**: 단축키 즉시 기존에 작성되어 있던 모든 메모 텍스트의 크기가 일괄 조정되며 다음 실행 시에도 유지
* **항상 위에 표시 (`Ctrl + T`)**: 다른 작업 창(IDE, 브라우저) 위에 띄워두고 빠른 메모 및 계산 가능
* **텍스트 파일 내보내기 (`F10`)**: 작성한 메모와 계산 기록을 언제든 외부 `.txt` 파일로 저장

### 4. 🛡️ 실시간 자동 저장 & 안전 백업

* **2초 주기 원자적 자동 저장**: 타이핑이 멈춘 후 2초가 지나면 임시 파일 교체(`fsync` + `replace`) 방식으로 안전하게 저장하여 정전이나 강제 종료에도 메모가 손상되지 않습니다.
* **직전 세션 자동 백업 (`.bak`)**: 프로그램 실행 시 이전 세션의 메모를 `.bak` 파일로 복사 보관하여 실수로 지워도 복구할 수 있습니다.
* **실행 취소(Undo) 보존**: `F4` 전체 지우기를 실행한 후에도 `Ctrl + Z`를 누르면 즉시 이전 메모로 복구됩니다.

## ⌨️ 단축키 안내

| 단축키 | 위치 | 기능 설명 |
| :--- | :--- | :--- |
| **`Enter`** 또는 **`=` 버튼** | 상단 입력창 | 수식 계산 실행 후 메모장 끝에 결과 덧붙이기 |
| **`↑` / `↓`** | 상단 입력창 | 이전에 입력했던 수식 히스토리 탐색 |
| **`Ctrl + Enter`** / **`F5`** | 메모장 본문 | 현재 줄 또는 선택 영역 수식 인라인 즉시 계산 |
| **`F1`** | 공통 | 수식 및 단축키 도움말 대화상자 표시 |
| **`F4`** | 공통 | 메모 전체 지우기 (확인창 후 삭제, `Ctrl + Z`로 복구 가능) |
| **`F6`** | 공통 | 다크 모드 / 라이트 모드 테마 전환 |
| **`F10`** | 공통 | 작성된 메모를 외부 텍스트 파일(`.txt`)로 내보내기 |
| **`F12`** | 공통 | 메모장 텍스트 전체 선택 |
| **`Ctrl + ↑` / `Ctrl + ↓`** | 공통 | 글꼴 크기 실시간 확대 / 축소 (설정 파일에 영구 저장) |
| **`Ctrl + T`** | 공통 | 창 항상 위에 표시 (Always on Top) 켜기 / 끄기 토글 |

## 💡 수식 입력 예시

```text
1 + 2 * 3                 -> 7
-5 + 3                     -> -2
1 / 2                      -> 0.5 (실수는 순수 10진수만 표시)
10 * 7 % 4                 -> 2
2 ^ 8                      -> 256
2 ^ 3 ^ 2                  -> 512 (2^(3^2) 우결합)
((10 % 6) * 2 / 4) ^ 8     -> 256
0xFF + 1                   -> 256 ( 0x100 )
0b1010 + 2                 -> 12 ( 0xC ) (2진수 지원)
0x1000 - 0x10              -> 4080 ( 0xFF0 )
0xFFFFFFFFFFFFFFFF         -> 18446744073709551615 ( 0xFFFFFFFFFFFFFFFF )
```

## 🚀 실행 및 빌드 방법

### 1. 개발 및 일상 실행

가상환경 활성화 후 실행하거나 **`run.bat`** 파일을 더블 클릭합니다:

```bash
# 의존성 설치
pip install -r requirements.txt

# 실행
python main.py
```

### 2. 독립 실행 파일 (.exe) 빌드

**`build_exe.bat`** 파일을 실행하면 자동으로 PyInstaller를 통해 독립 실행 프로그램이 생성됩니다:

* 빌드 결과: `dist/SmartMemoPad.exe` (단일 포터블 실행 파일)
* 파이썬이 설치되지 않은 다른 PC에서도 이 파일 하나만으로 즉시 실행 가능합니다.
* **배포 권장**: 소스 코드에는 `.exe`를 커밋하지 않고, GitHub 저장소의 **Releases** 탭에 업로드하여 배포합니다.
